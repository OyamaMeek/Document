# MV主角 · character.js 已接入 V2

`character.js`使用依据确认稿制作的透明角色素材，统一提供朝向、表情、动作、位置、缩放和动作周期。角色与手中的麦克风保存在同一张图像中，始终共同移动。

运行时只需要`character.js`和`assets/character-sprites.json`，没有第三方依赖，不调用图像生成服务。Node项目需采用ES module（本目录package.json已设置），支持JSON import attributes；已在Node 26.13.0验证。浏览器项目应通过HTTP服务或支持JSON module的构建器加载。

## 使用

```js
import { drawCharacter } from './character.js';

const actor = drawCharacter({
  direction: 'left',
  expression: 'shy',
  action: 'hold',
  prop: 'microphone',
  phase: 0.25,
  x: 320,
  y: 100,
  scale: 1,
});

const frame = `<svg xmlns="http://www.w3.org/2000/svg"
  width="640" height="640" viewBox="0 0 640 640">${actor}</svg>`;
```

返回值为SVG `<g>` 字符串，图像以data URI内嵌，保存生成的SVG后可独立显示。后续所有镜头调用此接口；不要在镜头里另画角色或独立移动手中的道具。

| 参数 | 可选值 | 默认值 |
| --- | --- | --- |
| direction | front正面、left朝画面左、right朝画面右、back背面 | front |
| expression | neutral平静、happy开心、shy害羞、sad难过 | neutral |
| action | idle站立、walk走路、jump跳跃、hug拥抱、hold持物 | idle |
| phase | 有限数字，每1为一个循环；可传入经过秒数／周期秒数 | 0 |
| prop | microphone麦克风；仅hold动作显示 | microphone |
| x、y | 角色局部原点在画布中的位置 | 0、0 |
| scale | 正数，等比缩放 | 1 |

全部80种朝向／表情／动作组合均可调用。背面看不到表情，因此共用相同背面素材。未知枚举、非有限数字、非正缩放和未制作的道具明确抛错。

角色图像放在局部x=-160…160、y=-20…480范围内；跳跃额外向上65。镜头需留出动作空间。左右侧面使用独立素材，胸牌文字不会被代码镜像。

## 动作与素材范围

每个动作使用独立关键姿势，phase控制走路起伏、跳跃起落、拥抱及持物的轻微摆动。角色跨画面的移动由镜头更新x、y控制。当前尚未制作完整交替迈步的逐帧步态，也不包含双人拥抱接触约束。

当前手持道具为麦克风。其他道具需先制作同样风格、正确握持且避让面部的素材，再加入模块；不能把道具悬空叠加到角色旁。

素材单格约200×350像素，适合中远景；大幅面脸部特写需要补充高分辨率素材。assets/character-sprites.json约10MB，模块导入时加载一次。

## 文件与检查

- 角色设定图-v2.png：确认造型的原始设定图，保留不变。
- 角色模块预览-v2.png／svg：由当前character.js实际生成的三视图、表情与动作预览。
- assets/*-atlas.png：四种表情的透明原始图集。
- assets/character-sprites.json：65张内嵌PNG素材；背面共用5张。
- build-assets.mjs：从图集的透明间隔建立素材索引，检查布局、alpha与数量。
- character.test.mjs：真实渲染、组合、动作周期、整体握持与错误输入测试。
- render-sheet.mjs：生成模块预览。

在工作空间根目录运行：

```sh
node --test 大肥鱼Claude装/character.test.mjs
node 大肥鱼Claude装/render-sheet.mjs
```

修改原始图集后再运行`node 大肥鱼Claude装/build-assets.mjs`。构建及测试脚本复用工作空间现有sharp；运行模块无需sharp或其他项目文件。

内置image_gen生成透明素材，提示词位于工作空间.agent/character-design/neutralAtlasPrompt.md、happyPrompt.md、shyPrompt.md、sadPrompt.md。视觉记录位于.agent/visual/character-module-v2.md。
