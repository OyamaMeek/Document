# 已完成：网盘式文件浏览界面计划

目标：将 `index.html` 改为 Apple 风格的网盘文件浏览界面，并让每次 push 后自动生成相同界面。

## 设计与范围

- 新增 `scripts/index.template.html`：浅灰背景、半透明侧栏、系统字体、蓝色文件夹图标，右侧显示文件名、类型和真实大小。
- 保留生成器的 Git 文件来源和安全链接；文件树增加路径、类型、大小属性，由原生 JavaScript 构建当前目录列表。
- 支持侧栏目录导航、进入文件夹、面包屑、返回上级、浏览器前进后退、即时全局搜索、无结果提示和文件直接打开；不添加上传、删除或账户功能。
- 无 JavaScript 时保留完整可展开文件树；内置响应式布局、键盘焦点、减少动态效果、减少透明度和高对比度偏好。
- 自身 `index.html` 不参与文件大小计算，避免结果依赖上一次页面大小；其他文件使用实际字节数。
- 现有 Actions 的命令与权限继续适用；范围涉及生成器、模板、测试、生成页面和工作记录。
